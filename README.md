# Pump & Dump Detection in Crypto Markets

Unsupervised anomaly detection system for identifying pump-and-dump manipulation schemes on Binance. The pipeline extracts microstructure features (log returns, volume z-scores, order flow imbalance, taker buy pressure) from Binance klines and aggTrades over a strict pre-event window, then scores each observation using an ensemble of Isolation Forest, Local Outlier Factor, and rolling Z-score models. Ground-truth labels from La Morgia et al. 2020 are used exclusively for post-hoc recall validation (Recall@LaMargia), never during training. The project is developed as an academic deliverable and as preparation for integration into Kaiko's Market Surveyor product, with direct applicability to MiCA Article 62 market abuse surveillance requirements.
